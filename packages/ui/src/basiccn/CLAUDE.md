# CLAUDE.md: `packages/ui/src/basiccn`

Loads when working under `packages/ui/src/basiccn/`: the tiptap v3 rich text editor. See `packages/ui/CLAUDE.md` for this package's other conventions.

Tiptap v3, built up from individual extensions rather than `@tiptap/starter-kit`, every mark/node in the schema is one explicit import in `utils/extensions.ts`. No Yjs/collaboration.

- **Layout**: `index.ts` (barrel, `Editor`, `BasiccnContent`, `basiccnTheme`), `editor.tsx` (the editable `Editor`), `preview.tsx` (read-only `Preview`, `editable: false`), `theme.ts` (the `typeset`-based class list), `types.ts`, `components/` (bubble menu, popovers, link hover card, slash menu), `utils/` (extension list, custom `Indent` extension, color/font-family palettes), `nodes/`, `plugins/`.
- **Theming rides on a `typeset` utility** (loaded globally via whatever global stylesheet a consumer imports), this is the one place `packages/ui`'s own rendered output still depends on the *consumer's* specific CSS, by design (typography rules are a styling concern, same "theming is the consumer's job" boundary as everywhere else in this package).
- **`BasiccnContent` is tiptap JSON**, not a serialized-string format, flows through `Editor`'s `value`/`onChange` and `@baseconfig/ui/forms`'s `RichText` field. Persisted server-side as-is inside a document's `data` (see `packages/config/src/db/CLAUDE.md`'s "Content persistence"), no separate serialization step.
- **Bubble menu, and a known tiptap/portal gotcha**: `components/bubble-menus.tsx` renders `@tiptap/react/menus`' `BubbleMenu`, plus a nested "More" popover and a link popover, each using the vendored `Popover`. Tiptap's `BubbleMenu` hides itself on editor blur unless the blur-causing mousedown happened inside the menu's own DOM subtree, and `PopoverContent`/`SelectContent`/`ComboboxContent` all render through a React portal, never a DOM descendant of the bubble menu. The fix is a `pinnedCount` ref in `BubbleMenus`, threaded via an `onPinChange(open)` callback; a custom `shouldShow` stays `true` while `pinnedCount > 0`. **Any new popover/select/combobox nested inside the bubble menu must call this callback on open/close.**
- **Watch for duplicate-registration crashes** when adding extensions: two extensions claiming the same ProseMirror plugin key throw `RangeError` at mount; two claiming the same *node* name only warn, second silently wins. Check `BasiccnExtensions` in `utils/extensions.ts` first.
- **`Placeholder`, `Gapcursor`, `Dropcursor`, `CharacterCount`, `UndoRedo`** all come from the single `@tiptap/extensions` package. **`TextStyleKit`** is configured with `fontSize`/`lineHeight`/`backgroundColor` all `false` (it already bundles `Color`+`FontFamily`).
- **Consumer**: `@baseconfig/ui/forms`'s `RichText` field (`../forms/fields/RichText/index.tsx`) is the only importer of `Editor`. No admin route imports it directly, collection editing is generic (`CollectionForm`).
